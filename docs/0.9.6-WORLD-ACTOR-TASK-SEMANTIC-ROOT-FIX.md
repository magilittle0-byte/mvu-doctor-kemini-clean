# 0.9.6 World 主体任务语义根修

## 当前源码对应的真实失败

0.9.5 在真实新聊天首轮中完成了原生 World 调用、JSON 解析、合并和读回。脱敏运行证据同时证明，`【本轮非玩家主体推进】` 在唯一 `extra-instr` 段出现一次、在原生最终 prompt 出现一次，完整附加段也只嵌入一次，并且原生模型返回非空。因此失败不在接线、解析或保存。

本轮唯一 Doctor 档案人物的目标依赖玩家尚未作出的选择。0.9.5 仍把她硬指定成第一行动者，同时允许“观察或计划调整”而没有要求变化进入原生持久字段。模型最终只复述了玩家建档和旧背景，没有让非玩家人物、势力或环境形成目标、尝试、代价与结果。该轮按人工语义门拒绝，不能作为通过证据。

## 最小适配

`profile-engine.js` 仍只返回一个不超过 2,200 字符的候选段。脚本轮换的第一人物保留为优先候选，以避免模型总挑同一类角色；但当其唯一合理动作只是等待玩家、重复正文或重复已完成行为时，任务明确回退到当前 World、已选世界书或近期对话中的既存人物、势力、组织或环境过程。

每轮要求一个与剧情时间尺度匹配、已经实施的非玩家行动，并按原生规则写入至少一个可跨轮追踪字段。只更新 `world_digest`、`influenceChain`、`reputation`，或把玩家建档、MVU 修复、正文、人物背景换句话复述，均不再满足该任务。隐秘已实施行动进入 `blackbox.secretActions`；公开且持续的具体迹象进入 `events` 等原生字段。

本次没有新增 scheduler、schema、解析器、门禁状态、存储、模型调用或失败重试。测试探针只增加脱敏布尔回执，证明任务在真实原生 prompt 中恰好出现一次；它不参与运行决策。

## 验证边界

静态、Node 与无头浏览器测试只能证明接缝、预算和原生状态所有权，没有证明真实模型会完成主体行动。运行代码或提示词已经变化，0.9.5 的全部真实证据失效；0.9.6 必须重新安装当前指纹，从一个全新聊天开始逐回合语义检查。完整通过真实酒馆协议前，本版本只能作为测试候选，不能声称正式可用。
