# 三模块接口与锁定合同 v1（第一阶段候选，尚未锁定）

仅第一阶段实现变量模块，后两模块显示尚未制作。

- 输入：作用域（聊天、角色卡、世界书）、本轮生成/消息/swipe身份、最终正文版本、本轮用户输入、更新前与当前MVU快照、当前变量规则及配置版本。
- 变量结果：状态、原状态与写后状态指纹、实际写入和读回结果、模型判断、未完成原因。空补丁只表示模型未提出修复，不代表独立证明剧情正确。
- 人物读取已确认的变量快照；世界读取完整档案与已确认变量。模块通过接口交换不可变副本，各自保存本模块数据；不得直接改另一模块内部状态。
- 模块注册仅用于调用已实现的模块，不新增业务调度器。禁用/未实现模块不能被调用，不能以旧实现补齐本阶段的成功计数。
- 后台模型请求不能阻塞主生成事件；新生成、swipe、编辑、删除、聊天切换导致旧输入失效时，旧任务零写入。
- 变量写入使用官方MVU；人物表属于医生；数据库本体独立填表；世界事件只由世界模块维护。
- 锁定文件包括模块源码、提示词、其传递依赖及相关接入文件；模型/规则/配置属于验收适用条件。后续模块新增接入必须保持已锁定行为。
- 当前没有任何锁定记录。只有当前候选完成真实阶段验收且无未解决错误后才生成锁定文件，哈希校验不能代替验收。
