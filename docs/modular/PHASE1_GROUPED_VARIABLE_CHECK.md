来源映射：

- 原样保留 Story Oracle 取材与原生连接发送，当前前后态、完整背景/规则/历史与原始复核材料；原样保留当前 MVU 一次 parseMessage、提交意图、写后读回与持久化核验。
- 最小适配数据库的 targetSheetKeys 为互不重叠的 MVU 路径范围。每组读取同一冻结基线，末尾明确只核对分配的字段及全部后代，并逐项给触发依据、当前状态与应有状态。其他变量仍可作为事实背景读取。全部组都收集成功后合并操作，才进入唯一官方解析和现有事务；任何组失败不得留下部分变量写入。
- 最小适配数据库的分组越权检测：组不能改其他组路径；move 两端均属于本组。跨组归属变化分别对各自字段产生增删，最终一次提交。现有前端只读与下划线保护仍独立生效。
- 新写 MVU 路径分组适配，因为数据库 sheetKey/DDL 与 MVU 嵌套变量、动态 record 及 JSONPatch 不兼容。复用当前权限编译器的路径声明和 ${a|b} 展开语法，结合前后态补入规则未声明的存储路径。父级容器声明覆盖子路径，避免重复归组；不按人物名、物品名或普通叙述关键词判断语义。每组初始最多8个互不重叠范围，控制单次待核对量，不减少总覆盖范围。
- 复用现有有限重试和过期守卫；分组只在当前 run 内收集，不新增外部任务、长期调度器或并行写入者。先顺序请求，进度显示当前组；用户继续生成或取消时，旧作用域结果不能提交。最终收据仍 semanticProof=false，不能把分组覆盖冒充语义验收。

没有采用此前失败的52编号覆盖器、原生任务替换或输出模板改写。它们保留在本机定位记录；候选先仅调整核对范围，验证真实效果后再决定。
