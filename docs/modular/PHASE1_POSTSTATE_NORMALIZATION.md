复用与最小适配：
- 原样恢复原版第一条MVU容错/补全/合并说明；仍以最终正文判断事件是否发生，不恢复“条目存在就绝不判错”的过强推论。

新写内容限于输入说明和复核材料的明确分工；不增加另一个模型、不把原更新隐藏到历史中。先完成针对性受控检查及冻结材料只读核对；只有新候选真实聊天12轮完整通过才锁定。
