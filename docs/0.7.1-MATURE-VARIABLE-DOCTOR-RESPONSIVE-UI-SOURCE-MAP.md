# 0.7.1 成熟变量医生与响应式 UI 来源映射

本版本先逐行读取成熟参考的真实调用链，再删除此前没有来源依据的语义门禁。本文只记录可公开的机制来源，不包含私人跑团正文、聊天文件名、API 信息或本地预设内容。

## 直接复用的成熟机制

| 来源作品 | 实际成熟机制 | Kemini Clean 0.7.1 落点 |
| --- | --- | --- |

## 最小适配

- 故事神谕只写 `latest` 且缺少写后读回，Kemini Clean 改为钉住聊天、楼层、swipe 和正文指纹，并保留旧 Doctor 的读回与回滚。
- 故事神谕的诊断块是一次模型结果；Kemini Clean 为刷新、重载和重 roll 增加“本回合完整替换块”：从上一楼层官方重放，并替换当前 swipe 的唯一变量块，不把旧 delta 与纠错再叠一遍。边界多义则零写入。
- 故事神谕缺失输出块时可能显示“无需改动”。Kemini Clean 将空数组诚实记录为 `model_reported_nochange`，不声称变量正确；缺块、解析失败和空补丁是不同结果。
- 旧 Doctor 的规则、Schema 和初始化读取保留；本地代码只做路径/所有权/操作基本安全，动态 Schema 的最终兼容性完全交给官方 `Mvu.parseMessage`。`/人物档案` 从变量差异中排除，并在提交前从最新完整状态原样带入。
- 写前日志不再只记录模型显式路径，而是记录“最新状态 → 官方候选”的全部非人物实际差异；官方联动出的派生字段因此能一起读回、撤销或回滚。
- 柏宝书的普通摘要可防抖落盘，MVU 关键变量不适用；Kemini Clean 必须等待持久化并重新读取。
- 生理引擎的领域字段和柏宝书的摘要 Schema 均未移植，只复用通用解析、定向修复与旧值保留语义。

## 删除的无来源实现

以下机制不是上述成熟作品的变量修复主体，且会把脚本的有限文本匹配冒充语义证明，因此从 0.7.1 删除：

- 玩家 `键:值` 正则收据与候选闭合门；
- 根据叙事词汇生成的本地风险检查表；
- 原变量块双重重放后形成的 baseline 空补丁门；
- 从自然语言规则正则推测脚本托管字段；
- 官方 MVU 拒绝部分路径后拆分并提交剩余补丁；
- 要求 Analysis 证明“无需修复”的文本门禁。

现在的职责边界是：模型根据完整权威材料判断“本回合完整正确块是什么”；脚本只判断“格式能否唯一恢复、是否越过人物/只读所有权、官方 MVU 能否执行、未声明外部状态会不会被覆盖、写入是否真实读回、失败能否恢复”。

## UI 来源与适配

| 来源 | 成熟机制 | 本次适配 |

| 柏宝书 `App.vue` | 弹窗与滚动容器分离、移动抽屉、Pointer Capture、Escape 和可访问 dialog | 保留 Kemini Clean 自有 HTML/视觉，只复用模态边界、焦点和触控交互原则 |

| 故事神谕可视窗口 | `visualViewport` 重算和手机不强制聚焦 | `visualViewport` 的 resize/scroll 共同更新 CSS 视口变量，避免软键盘和缩放把关闭键挤出屏幕 |

UI 结构与视觉代码仍为 Kemini Clean 新写，没有复制任何参考作品的具体标记或配色。

## 所有权与验证边界

- 预设负责正文生成前的视角、篇幅、首次出场和玩家边界；0.7.1 没有上传预设。
- MVU 负责实时变量；Doctor 只在接受正文后把唯一变量块替换为经官方重放验证的本回合完整块，并验证持久读回。
- 人物档案仍由人物医生整张原子提交；数据库仍独立填表；世界仍由 `subjects + changes` 权威推进。
- 自动语法、解析、回归和响应式检查只能证明候选具备自测条件，不能替代真实模型、真实宿主持久化或十二回合真实酒馆门禁。
