# 世界引擎独立候选

当前是性能适配准备：保留原生世界引擎，模型输入移除纯定位/写入诊断元数据；完成结果以完整语义输入核对后复用，手动修复始终重新请求。新版 P2 尚待真实阶段验收，P3 精确依赖将在新 P2 锁生成后绑定；期间世界 loader 暂停。P3 启动仍验证两个模块的锁、运行与配套文件，旧 phase2 证据只属于旧版，不能作为新候选放行依据。详见[本次来源和边界](P3_SEMANTIC_REUSE_SOURCE_MAP_2026-09-20.md)。

安装 `world/install.json` 为独立的酒馆助手全局脚本。它与变量、人物档案脚本同时启用。加载本身不会重新推演旧回合；下一次正常正文及档案完成后自动运行，也可以点击世界面板的“修复本轮”。

模块根据当前最终正文、已确认 MVU、完整 NPC 档案及角色卡/世界书，在原生世界引擎的一次调用中处理行动、裁决和后果。完整世界保存在独立的 IndexedDB 命名空间。世界面板显示保存状态、世界资料、黑箱和召回证据。黑箱与完整内部摘要不会直接作为主模型召回内容。

每次自动世界推进或点击世界修复按钮最多调用模型一次，自动重试为零。同一精确目标、版本、完整实际输入的已完成成功结果才可零请求重绑读回；失败或待修结果不能冒充恢复。运行中仍保留严格人物记录、变量与作用域校验。新三模块组合的普通动作上限为变量一次、人物一次、世界一次；正文、数据库等其他扩展的调用另计。

模型判断可能出错。修复按钮会读取当前输入，以本轮推进前的世界重新生成，替换本轮结果；不会把修复点击算成新的世界轮数。新结果保存失败时保留上一份完整世界和对应召回记录。修复也可能再次误判，不以代码声称模型内容必然正确。

召回只使用公开字段；记录是否进入请求、被哪一条接受正文绑定，以及是否找到完整字面证据。字面证据不等于完全证明语义采用。没找到证据的内容保留，已匹配的同一后果不再作为新事件重播；同实体的新结果替代旧待呈现结果。真实验收仍需独立检查后果是否自然进入正文、有没有泄漏秘密或替玩家行动。

本候选尚未完成真实门禁，不能作为完整医生已经可用或第三阶段已锁定的声明。
