# 0.6.11 人物发现与世界公开投影误重试根因修复来源映射

## 真实失败链

0.6.10 的同一全新聊天在第 1、2、3 回合分别记录到 Doctor 128199ms、117347ms、131993ms；第 3 回合成为第二次超过 120 秒，真实门禁立即失败。

- 第 1 回合：变量模型 1 次；人物模型因脚本把机制字段、动作词和连接词当成必建档人物而调用 3 次；世界模型 1 次。
- 第 2 回合：变量模型 1 次；人物模型因脚本把连接词当成必建档人物而调用 2 次；世界模型 1 次。
- 第 3 回合：变量模型 1 次；人物模型 1 次；世界模型把一个在正文中公开发生的可观察言行仅因含有“秘密”字样判成私密泄露，整次调用重跑 1 次。

变量、档案、世界事务最终均读回成功，但错误的候选门让本可一次通过的模型阶段发生整次重跑。这不是总超时或输出预算问题，而是两处上游分类器制造的重试。

## 直接保留

- 变量医生先完成真实 MVU 重放、修复、读回和正文单块保存。
- 人物档案完整字段、十四轴同票、候选合并、整批原子写入和读回验证。
- 世界私有完整状态、Actor 行动/世界裁决分离、两阶段持久化和下一轮一次性公开召回。
- 三阶段顺序和失败恢复；不设置砍任务的总超时。

## 最小适配

1. `discoverProfileSubjects` 仅留下显式说话标签和稳定 ID 这种高置信脚本锚点；删除自由散文 `任意中文片段 + 动作动词` 的伪 NER。
2. 档案模型仍必须审阅完整最终正文并主动发现全部实际参与的稳定 NPC；高置信锚点是必须覆盖的下限，不冒充完整人物名单。
3. 每张新档案必须至少有一个 name/alias 是最终叙事逐字出现且形状像身份的表面；连接词、代词动作片段和机制字段即使字面出现也不能成为身份或别名。
4. 裸“秘密”不再单独触发泄密；仍拒绝内心、真实目的、暗中行动、秘密身份/计划/记录的确定断言，以及其他现有全知标记。

## 必须新写及原因

- Kemini Clean 的扁平完整 JSON 档案没有旧医生 `narrative-v1` 的 ActorRef/coverage-unit 数据结构，不能直接复制旧解析器；新增一个小型 `profileIdentitySurface` 门适配现有 name/aliases 与原子票据提交。
- Kemini 的公开投影字段与故事神域 `blackbox/winds` 字段不同，不能复制其状态结构；只在现有 `publicProjectionLeak` 内收窄“秘密”语义形状。

没有新建调度器、第二状态机或第二持久层；预设、数据库和正式仓库不在本轮修改面。
