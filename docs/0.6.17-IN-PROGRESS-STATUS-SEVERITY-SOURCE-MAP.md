## 真实故障链

0.6.16 在真实 TauriTavern 首回合按 `accepted-final -> 变量 -> 人物 -> 世界` 顺序运行。变量事务已经提交并读回，人物模型正在补全档案字段时，Doctor 根节点却从 `busy` 短暂变成 `error`；最终人物档案、世界事务和完整运行又正常提交并回到 `ready`。

## 最小适配

`statusPresentation` 先取得 `pending = runtimeHasPendingWork()`，并只把阶段标题本身含“失败/无法/错误/不一致/未确认”的状态视为明确终态失败。仍在运行且阶段标题不是失败时，详情可如实列出待补字段、解析问题和本轮修复理由，但 UI 保持 `info/busy`。任务退出待处理态后，原有全文错误判断继续生效。

这不会把真实失败染蓝：`MVU变量修复失败`、`人物档案失败`、`世界引擎失败`、`正文结构无法安全修复` 等阶段标题仍直接进入红色错误；取消与隔离语义也没有改动。
