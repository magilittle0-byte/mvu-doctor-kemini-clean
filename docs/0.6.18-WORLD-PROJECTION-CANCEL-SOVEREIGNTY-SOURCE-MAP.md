# 0.6.18 世界公开投影与取消主权来源映射

## 真实故障路径

1. 最终正文进入 Doctor 后，变量与人物档案已经提交。
2. 世界模型生成了可保留的医生私有状态，但个别 `publicSurface`、`publicClues` 或新揭示证据不满足公开边界。
3. 0.6.17 把公开投影的局部错误当作整个世界候选失败，重新请求完整世界 JSON；真实回合因此连续发起三次世界模型调用并超过 120 秒。
4. 用户取消后，会话 epoch 已经变化，但 `advanceWorld` 把会话作废异常继续当成可重试世界错误；迟到协程又在 `acceptFinal` 中写入 `world_failed`、失败运行报告和红色状态，覆盖了黄色取消提示。

## 成熟来源与复用边界

| 机制 | 来源 | 采用方式 | 适配边界 |
|---|---|---|---|
| 中止后立即停止自动重试，`AbortError`/signal 单独归类，`finally` 复位运行状态 | 故事神域 `world-engine-evolution.js`、`memory-engine.js` | 最小适配 | Clean 使用会话 epoch、chatId 与宿主生成，不能原样搬用其全局 `_abortController`；复用“中止不是普通失败、不得进入下一次重试”的控制流。 |
| 模型返回后再次核对任务与目标主权，迟到结果禁止提交 | 旧 Doctor `v2/runtime/lease.mjs` 与 `barrier.mjs` | 最小适配 | Clean 不引入另一套持久任务租约；在现有 session/epoch/chatId 上增加统一判定，并在每个长异步阶段返回后复核。 |
| 只修能确定的局部格式，保留其余有效内容 | 数据库兼容层 `database-patches/src/core.mjs` | 最小适配 | 数据库修的是 SQL；Clean 对世界候选只清除不可安全公开的投影字段，保留医生私有摘要、镜头外行动、人物行动与世界裁决。 |
| 公开投影消费前已有 `safePublicText` / `safePublicArray` 防泄漏 | Kemini Clean 当前 `core.mjs` 世界召回层 | 直接复用 | 把相同的判定前移到世界候选验证前，避免为公开字段重生整份私有候选。 |
| 黑盒事实必须与公开传播链分离 | 故事神域 `world-engine-rules-loader.js`、`world-engine-evolution.js` | 规则保持 | 私有字段不删；仅在缺少正文精确证据时把新 `observed` 降为 `hidden`，既有已揭示事实恢复旧公开证据。 |

## 未直接复用的作品

- 糖糖公司与 Izumi 负责正文生成前人物和文风，不拥有 Doctor 世界任务取消或公开投影提交时序。
- 缝合怪负责提示词整合与规划，不拥有世界候选持久化。
- Z论坛与角色卡/世界书资料提供叙事结构，但没有与本故障相同的异步取消事务。

因此本版不新建并行状态机，只在现有世界候选净化、会话断言和原子提交路径上补齐缺失的主权检查。
