安装仓保持为 `magilittle0-byte/mvu-doctor-kemini-clean` 的 `main`。先通过扩展管理器更新同一安装目录，再将 `profiles/install.json` 导入酒馆助手全局脚本并启用，重新加载页面。人物模块和变量模块各有独立面板。自动建档及相关档案召回默认开启。

普通正文完成、变量模块完成保存读回后，医生自己发现人物，用正文、MVU、角色卡和世界书生成完整档案。预设无需输出专门的档案标签或票据。每个人包含36项文本和8项列表，表格索引与展开详情读取同一份存档。姓名相同不会由脚本直接合并；已有身份由模型依据记录对齐，新增人物由脚本分配独立ID。

每次处理最多一次模型请求，同时发现人物、新建完整档案并更新旧人物。新人物仍须完整44字段；旧人物只返回变化字段，省略字段保留，变化数组整体替换，合并后再次完整验证。明确无变化者保留原内容。格式、缺项或连接失败不会自动追加请求。面板显示本次发起次数。单人物内容失败时保留旧完整版本，其他成功人物仍会保存；未知身份、来源或整体合同错误拒绝该响应，不能假报全部完成。

点击“修复本轮档案”会重新读取当前正文和已确认变量，最多再请求一次。完整或部分结果继续使用原有反馈；已保存的整体响应校验失败只提供白名单错误码对应的固定说明和原退休许可，不发送旧原文、旧人物值或错误消息。固定诊断绑定原有目标/MVU收据及解析器使用的正文、玩家排除信息、已有档案；这些依据改变时不带旧诊断。动态世界资料重新读取不使这段无候选值的历史诊断失效，模型仍须按本次完整资料重新生成。这个边界只用于修复说明，不用于复用已完成结果；结果复用仍核对完整权威资料。44字段、逐人保存和读回要求不变。生成式模型仍可能误认身份、漏人或设计不合适的内容，按钮不保证单次就消除幻觉。

只有本版本同一目标的完整成功结果、实际输入/权威/配置及已保存输出仍匹配时，重复自动通知才会零请求读回；手动按钮始终重新生成。刷新恢复只读存档，不代表内容错误得到更正。本轮修改前来源及边界见 `P2_SINGLE_CALL_SOURCE_MAP_2026-09-20.md`。

换聊天、改正文或开始新生成时，旧任务停止写入；档案按聊天分支保存。取消和关闭自动建档不删除已有完整档案。相关人物资料会进入后续正文提示，私有背景仅供对应NPC塑造，不代表玩家或其他NPC知道。注入观察与正文是否正确使用分开核验。

人物模块只写自己的IndexedDB命名空间和自己的召回提示，不接管数据库表格、不写MVU、不执行世界行动。每份正式档案必须先完整生成再保存读回；失败候选与模型原文仅保存在用户本机模块记录里。
